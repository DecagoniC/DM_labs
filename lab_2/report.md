# Лабораторная работа №2

**Тема:** интерпретатор многозначных логик и проверка семантических свойств формул.

**Вариант:** 3.

**Пояснение задачи и теория:** [theory.md](theory.md).

## Логические системы и семантика

| Система | Обозначение | Значения истинности |
| --- | --- | --- |
| Классическая двузначная логика | cl | 0, 1 |
| Сильная трёхзначная логика Клини | k3 | 0, 1/2, 1 |
| Трёхзначная логика Лукасевича | l3 | 0, 1/2, 1 |

| Связка | Правило вычисления |
| --- | --- |
| ¬a | 1 − a |
| a ∧ b | min(a, b) |
| a ∨ b | max(a, b) |
| a →K3 b | max(1 − a, b) |
| a →L3 b | min(1, 1 − a + b) |

**Соглашения:**

- **общезначима** — значение 1 при всех интерпретациях;
- **выполнима** — существует интерпретация со значением 1;
- **невыполнима** — нет ни одной интерпретации со значением 1; это не то же самое, что тождественная ложность;
- **тождественно ложна** — значение 0 при всех интерпретациях;
- для логического следования контрпример — интерпретация, в которой все посылки равны 1, а заключение не равно 1.

**Пример из задания.** Для формулы p → q при p = q = 1/2:

| Система | Значение |
| --- | --- |
| K3 | 1/2 |
| L3 | 1 |
